# Публикация TypeGame

- Репозиторий уже подключён к GitHub.
- Основная ветка: main.
- GitHub Pages публикует игру из ветки main.
- Когда пользователь пишет «загрузи на GitHub», не создавай новую ветку и Pull Request.
- Не требуй GitHub CLI (gh).
- Используй установленный обычный Git.
- Сначала проверь git status и изменения.
- Добавь только файлы этого проекта.
- Создай commit с коротким понятным описанием изменений.
- Выполни git push origin main.
- Никогда не используй force push и не удаляй файлы без разрешения.
- После отправки сообщи, какие файлы загружены, и дай ссылку:
  https://turkcemateryaller-ux.github.io/TypeGame/
